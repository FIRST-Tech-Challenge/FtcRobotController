-- -

<h3 style=""> Tags </h3>

> Follow this naming convention: **v[Major].[Minor]-[Event]**

<table style="font-size: 0.75rem; white-space: pretty; max-width: 40rem;">
    <tr>
        <th> Tag Structure </th>
        <th> Example </th>
        <th> Used For </th>
    </tr>
    <tr>
        <td> Scrimmage / Meet Build </td>
        <td> <code>v1.0-meet1</code> </td>
        <td> A stable code package ready for league meets or scrimmage days. </td>
    </tr>
    <tr>
        <td> Qualifier Build </td>
        <td> <code>v2.0-qualifier</code> </td>
        <td> Code used at formal regional qualifying tournaments. </td>
    </tr>
    <tr>
        <td> Interstate / Regionals </td>
        <td> <code>v3.0-regionals</code> </td>
        <td> High-stakes tournament builds with locked-in autonomous coordinates. </td>
    </tr>
    <tr>
        <td> Emergency Patch </td>
        <td> <code>v2.1-qualifier-fix</code> </td>
        <td> A fast fix deployed mid-tournament when a servo map changes between matches. </td>
    </tr>
</table>


<br></br>


### Branches
> Follow this naming convention: **[type]/[what was added]**

<table style="font-size: 0.75rem; white-space: pretty; max-width: 40rem;">
    <tr>
        <th> Branch Structure </th>
        <th> Example </th>
        <th> Used For </th>
    </tr>
    <tr>
        <td> feature </td>
        <td> <code>feature/new-feature</code> </td>
        <td> Development </td>
    </tr>
    <tr>
        <td> bugfix </td>
        <td> <code>bugfix/issue-123</code> </td>
        <td> Bug Fixes </td>
    </tr>
    <tr>
        <td> hotfix </td>
        <td> <code>hotfix/critical-bug</code> </td>
        <td> Critical Fixes </td>
    </tr>
    <tr>
        <td> release </td>
        <td> <code>release/v2.1.0</code> </td>
        <td> Releases </td>
    </tr>
</table>


<br></br>


### Folders
> Follow this naming convention: **[name] all lower case**
