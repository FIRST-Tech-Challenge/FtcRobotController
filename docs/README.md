# Pollen documentation

These documents travel with the code on this branch. For the cleanup build,
start with the first two links.

| Document | Audience and purpose |
| --- | --- |
| [Operating manual](POLLEN_AUTONOMOUS.md) | Drivers and students: choose A/B, position the robot, use INIT controls, run, stop, interpret warnings and record tested settings. |
| [Code README](../TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pollen/README.md) | Programmers: file map, hardware, sequence behavior, calibration, tests and deployment with `ftcgradle`. |
| [Shoot-first calibration reference](POLLEN_SHOOT_FIRST.md) | Mentors and programmers: diagonal geometry assumptions and calibration evidence. |
| [How this compares with the old code](POLLEN_AUTONOMOUS_EXPLAINED.md) | Students: concepts and translation from earlier robot routines. |
| [Historical preparation plan](POLLEN_WEDNESDAY_PLAN.md) | Background only; old patch/application instructions are superseded. |

Menu controls belong in the operating manual. Architecture belongs in the code
README. Update both when behavior changes; avoid maintaining a second copy in a
wiki or an unversioned handout. A printout is useful at practice, but check its
build/commit against the installed robot code.
