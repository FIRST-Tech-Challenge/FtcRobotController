# FTC TEAM 31830 - MIGHTY MANGOS 🥭
**FIRST Tech Challenge 2026-2027 Season: BIOBUZZ**

This is the official software repo for team 31830. This codebase contains all the code necessary to run the robot.

## Dev Workflow
1. **Branching** - all code must go into a feature branch before being pushed to the master branch
2. **Hardware Testing** - all code must be confirmed to work before being merged
3. **Task assignment** - tasks are delegated by an internal issue tracker

## Quick start:
1. `git clone https://github.com/nan0b1t/ftc-team-31830-code.git
2. Open in android studio or other editor/Ide
3. Let gradle sync
4. Use built in Android Studio tools or `./gradlew assembleDebug` to build code
5. Use built in tools or `./gradlew installDebug` to run
